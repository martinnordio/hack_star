Concepts glossary

Base snapshot
The saved state a tab loaded before its local edits; it is used to distinguish local changes from remote changes.
Remote merge candidate
The latest shared storage combined with local changes, ready to be persisted.
Same-ID collision
Two tabs independently choose the same stable identifier, making replacement by id a potential data-loss path.
Full-string validation
A pattern must match every character of the value, not just a prefix or substring.
Pydantic field validator
A model-boundary check that rejects invalid network payload fields before downstream code handles them.

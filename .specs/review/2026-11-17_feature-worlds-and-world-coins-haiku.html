Author Q&A

Are old saves safe?
Yes. Versions 2 to 7 migrate forward; the dev account's real version 7 save loaded with fighters and credits unchanged.
Can a world-coin code be used again early?
Yes, by clearing the browser's data: the dates are kept in each account's progress on the device because the game has no server accounts (decision D10).
What happens to a friend on the previous version?
In Canyon Small nothing changes. In any other world the server sends an update message, closes the connection and tells the host who was removed.

Adds what one tab changed to the latest saved value, so changes in two tabs both count.
Member version
A number a device sends when it joins a room; a missing one means the previous version.

# Spec kit of Hack star

Generated by spec-nx `b03a057` (v0.3.0) with Claude Opus 5.5 on 2026-11-13. Do not edit the
files in this folder by hand: `GENERATE KIT --update` replaces them. Project rules go into
`.specs/guidelines/`; the game's specs into `.specs/features/`; the overall game idea is
`.specs/overall_req.md`.

## How to use a stage

In the AI chat of VS Code, load the stage prompt and type its command:

```
Load .specs/kit/<stage>/prompt.md.
<COMMAND>: <arguments>
```

## The workflow

One feature = one spec = one branch `feature/<name>` = one GitHub issue = one pull request.
Every commit message carries the issue reference `#<n>` — `guidelines/commits.md`.

| # | Stage | Command | Result |
|---|-------|---------|--------|
| 1 | requirements | `REQUIREMENTS: <name> — <what you want>` | Part 1 of `.specs/features/<date>_<name>_spec.md`; answer its open questions with `REQUIREMENTS: <spec file> — <answers>` |
| 2 | plan | `PLAN: <spec file>` | Part 2: Steps, decisions, Definition of Done |
| 3 | implementation | `IMPLEMENT: <spec file>` — once per Step, commit after each | Server / UI code + the Step marked done |
| 4 | review | `REVIEW: <spec file>`, `CODE REVIEW: <spec file>` | HTML review page in `.specs/review/` (index: `.specs/review/index.html`), semantic diff for the pull request; findings in the Review Log |
| 5 | implementation | `CLOSE: <spec file>` | Spec moved to `.specs/features/done/` |
| 6 | pr | `PR: <spec file>` | Pull request (with the semantic diff) and issue updated with the spec summary |

## Now and then

| Command | Stage | Does |
|---------|-------|------|
| `CREATE ISSUE: <spec file> [parent <n>]` | requirements | Creates the GitHub issue of the spec (optionally a sub-issue of a parent); offered when the requirements are finished |
| `UPDATE ISSUE: <spec file>` | requirements | Summary of the spec into its issue |
| `GUIDELINES: <language>` | guidelines | Writes or updates `.specs/guidelines/<language>.md` (python, typescript, svelte, powershell) |

## Settings

- `.specs/spec-nx.json` — the team's answers (committed).
- `.specs/spec-nx.local.json` — your answers, e.g. your shell (not committed).
- Update the kit: `git submodule update --remote .spec-nx`, then load
  `.spec-nx/generator/prompt.md` and run `GENERATE KIT --update`.

Author Q&A

Why are the trophies given when the match ends and not when the result screen opens?
D5 (the original game's D3): MatchArena._store_result_when_over runs once per match, calls GameState.award_trophies and saves at once, so Back during the 1.5 s wait or a closed tab keeps them; the screen only reads last_result["reward"] (record block match-end).
What happens to a damaged or edited save file?
D3: SaveData checks every field; unknown fighters, hacks and skins, wrong types and numbers out of range are left out and the sample progress fills them; a broken, non-object or newer file gives no hacks and the sample progress (test_save_data_v2.gd, test_game_state_save.gd).
Can a test run change the player's own progress?
Not through tools/test.ps1: the pre-run hook points GameState.save_path to user://test/run_save.json before any test (D7); the files that check saving use their own path. GUT started another way does not load the hook (finding 4).
Do the hacks change trophies or get saved into the progress?
No (S13, D4, D5): award_trophies reads no hack, and unlock_all does not add to "unlocked" (test_game_state_save.gd, test_match_trophies.gd); the hacks are saved in "hacks" only.

A node Godot adds at the root at start-up and keeps between scenes; GameState owns the progress and the save file, so the arena asks it to award and save instead of writing the file itself.
Session-only result
last_result lives in memory only; the result screen reads the reward from here, so the screen never recomputes trophies (D5).
Static function
A function of the class, called as Trophies.reward(...) without an instance; it keeps the rule pure and testable without a scene.
match statement
GDScript's pattern match on a value; an enum value not listed (TIME_UP) falls through to return 0.
maxi
The integer maximum of two ints; here it keeps the new count at or above the last Prestige floor of the old count (S6).
Dictionary.merge
Copies the keys of another dictionary into this one; with overwrite true the saved value wins, and fighters missing from the file keep the sample's value.
Unlocked list vs is_unlocked
unlocked is the saved list only; is_unlocked() also counts the unlock_all hack. Using the list here drops a fighter chosen through the hack after a restart (finding 1).
user://
Godot's per-project user folder; on Windows under %APPDATA%\Godot\app_userdata, in the browser kept in IndexedDB, so the progress stays on one device and browser.
FileAccess and closing
Opens the file for writing (truncating it); the file is closed and flushed when the last reference goes away at the end of the function, which on the web also syncs IndexedDB.
push_warning

Concepts glossary

SubViewport
A Godot node that renders its children into its own off-screen area of a given size.
canvas_items stretch
Project setting: the 2D UI is laid out at the base size (1280Ã—720) and scaled to the window; with aspect expand the short side grows.
push_input
Viewport.push_input hands an input event to one viewport, as if the player had sent it there.
emulate_mouse_from_touch
Project setting (default on): Godot's Input turns a screen touch into a left mouse press and release.
unproject_position
Camera3D.unproject_position gives the 2D screen point where a 3D point appears.
theme_override_font_sizes
A per-node override of the theme's font size, stored in the scene file.
HTTPRequest / WebSocketPeer
Godot's built-in HTTP client node and WebSocket client; both work in the web export.
